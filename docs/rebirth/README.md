# 暮影紀元：裂隙覺醒 · Rebirth 1.2

獨立可玩的網頁闖關原型。一位逐光者，武器決定職業，造型另行穿戴。

## 上傳 GitHub（保留舊遊戲）

1. 解壓縮下載包，會看到 `rebirth` 資料夾。
2. 進入 GitHub 專案的 **docs 資料夾**，選 Add file → Upload files。
3. 把整個 `rebirth` 資料夾拖入，確認檔案路徑為 `docs/rebirth/index.html`，以及同層 assets、vendor 等資料夾，再 Commit changes。
4. GitHub Pages 保持 `main` / `/docs`。等 Actions 的 Pages 部署成功。
5. 在你原本遊戲網址末尾加上 `rebirth/` 開啟新版，例如專案名稱是 Twilight-Expedition，路徑就是 `/Twilight-Expedition/rebirth/`。

**不要只上傳 index.html，也不要取代 docs/index.html。** 舊遊戲與舊進度保留；新版從獨立存檔開始。

本機測試請用 HTTP 伺服器（例如 Python `python -m http.server 8000`），再開啟 localhost；直接雙擊 file:// 不支援模組、素材讀取與離線快取。

## 已實作

- 原創單角色封面、真實素材載入進度、完成後顯示登入／註冊或訪客入口。
- WebGL / Three.js 真 3D 場景：透視鏡頭、動態陰影、立體石柱與門、關節化人物、行走與武器動作。裝置不支援時自動回到 2D 相容模式。
- 五種初始武器均可至裝備背包免費切換：拉弦長弓、近戰扇形大劍、往返迴旋鏢、追蹤菱形符文法杖、即時穿透與折射雷射。
- 火球、箭矢、冰晶、鋸齒雷電、地面預警、劍氣和雷射使用不同形狀。怪物死亡音效，營地／戰鬥／首領三種程序音樂。
- 三章、每章隨機 20 / 30 / 40 / 50 小關；每十關元素首領；清房後走入上方門，經轉場前往下一間。
- 19 種敵人圖鑑與行為、逐章解鎖、8 種每日任務、七日新手任務與傳說鏡影裝備。
- 五套造型、僅穿戴中提供加成；免費券抽取、重複轉碎片與新造型保底。
- 裝備圖片、強化、同類武器合成、對應戰力與分身特性。
- 本機存檔、房間入口續關、JSON 備份；可另設定真實 Supabase 登入與同步（見 CLOUD_SETUP.md）。
- PWA manifest、圖示與離線快取。支援的瀏覽器可以加入主畫面；這是網頁 App，不是 APK。

## 操作

桌機 WASD／方向鍵移動，Space 衝刺，P 暫停。手機使用搖桿和衝刺鍵。自動攻擊最近目標，大劍需要靠近。音樂需使用者首次點擊後才能開始，設定可以分別調音樂及音效音量。

## 測試與限制

- 自動化檢查：章節、門轉場、19 敵人、首領元素、裝備與任務；另驗證五武器實際傷害方式、延遲發射、造型加成／保底與入口門檻。
- 使用官方 Three.js 建立三章、所有怪物和五武器的場景圖，驗證幾何物件和世界座標皆有效。
- 測試用雲端瀏覽器停用了 WebGL，已確認它會回退至 2D；**真正 GPU 的 3D 畫面、陰影效果及手機效能尚待實機驗證**。模型為程序化 low-poly 原型，不是商業角色美術資產。
- 帳號後端預設未設定，因此註冊／登入按鈕會誠實停用。真實後端驗證與跨裝置同步需自行設定專案後測試。
- 續關以房間為單位，不是逐秒重播。未完成房間會重新開始。
- 沒有真實儲值、付款或原生商店上架。若要發行 App，仍需原生封裝與實機測試。

## 1.2 修正

- 五套造型改為不同輪廓：兜帽、銀髮馬尾與分岔外套、赤髮頭帶與單肩甲、法師帽長袍與浮晶、王冠重甲與寬披風。2D / 3D 共用相同造型身分；衣櫥預覽不拿武器。
- 營地下方不再列出武器按鈕，統一到裝備背包更換。角色仍顯示目前武器。
- 營地與三章場地配色更明亮；角色腿部步幅、肘部、軀幹擺動、拉弦與大劍揮砍的時間曲線獨立變化。
- 新增投射物歷史軌跡、施法光環與命中放射火花；相容模式與 3D 都有。特效不改變傷害或判定，3D 拖尾數量設上限。
- 裝備貢獻戰力改以該武器自己的職業為基準，避免初始迴旋鏢顯示負貢獻。穿戴比較仍會顯示實際總戰力增減。
- 繼續沿用新版既有存檔鍵與造型 ID，更新不清除本機進度。
